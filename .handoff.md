# ST-3 Handoff

## What changed

- Removed `test/neo_connection_health_monitor_test.dart` (ST-1/ST-2 smoke).
- Added `test/connection_health_monitor_test.dart` — full 14-case
  behavioral suite (16 tests total: 14 + 2 supplementary).

## Test infrastructure

- `package:fake_async` drives every timer-based test — no real wall-clock
  waits.
- `package:http/testing.dart` `MockClient` fakes the server probe at the
  `BaseClient.send` level (works with our `http.Request` + `followRedirects = false`
  pattern; verified).
- `_FakeInternetConnection extends InternetConnection` overrides
  `hasInternetAccess` — the only API the monitor calls. Uses
  `InternetConnection.createInstance()` so no real probe configuration runs.
- Shared `_build` helper injects all DI seams with sensible defaults
  (jitterRatio: 0.0 by default; only the jitter tests enable it).
- Seeded `Random(42)` is the default.

## For the reviewer

- The `_FakeInternetConnection` subclass approach is the cleanest under
  v3.0.0; `InternetConnection` is a non-final concrete class.
- Test #14 deliberately tests the FORMULA (mirroring the monitor's
  `_nextDelay`) rather than poking private internals. Combined with #14b
  (integration via `fake_async`), the jitter behavior is locked down at
  both layers.
